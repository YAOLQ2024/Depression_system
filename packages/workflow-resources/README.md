# Workflow Resources

Canonical home for runtime product resources.

Structure:

- `workflows/`
  Stage-level product workflows.
- `doctor-personas/`
  Virtual doctor selection metadata.
- `interview-scripts/`
  Rule-based interview trees for V1.
- `digital-human-playlists/`
  Fixed video/question manifests for digital human consultation.
- `scales/`
  Structured scale definitions and source references.
- `risk-rules/`
  Rule-based risk stratification placeholders.
- `intervention-programs/`
  Intervention catalog and templates.
- `prompts/`
  Reserved for future AI-enhanced prompts.
