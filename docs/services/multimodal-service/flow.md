# `multimodal-service` 服务流程设计

## 1. 多模态会话启动

1. 上游服务创建多模态采集会话
2. 绑定所属业务会话和当前阶段
3. 返回采集会话标识

## 2. 采集与处理流程

### 2.1 语音链路

1. 接收语音片段
2. 执行语音转写
3. 计算声学/情绪特征
4. 保存转写文本和特征结果

### 2.2 表情链路

1. 接收图像或视频片段
2. 执行表情识别
3. 提取表情特征与质量分数

### 2.3 姿态链路

1. 接收视频帧或关键点序列
2. 执行姿态特征提取
3. 输出标准化姿态指标

### 2.4 脑电链路

1. 接收脑电片段
2. 校验通道与采样信息
3. 提取基础脑电特征

## 3. 特征包汇总

1. 汇总各模态片段
2. 按时间窗口对齐
3. 补充质量标记
4. 生成标准化特征包
5. 返回给上游服务或供下游拉取

## 4. 异常分支

- 某一模态缺失
- 采集质量不足
- 模型处理失败
- 时间同步失败

## 5. 实现约束

- 缺失部分模态时不能让主链整体阻塞
- 所有输出都必须可追踪到来源片段
- 风险服务使用它的结果时，必须遵守“辅助判断”原则
