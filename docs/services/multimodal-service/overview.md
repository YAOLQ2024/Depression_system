# `multimodal-service` 服务设计概览

## 1. 概述

`multimodal-service` 负责 MCS 中语音、表情、姿态、脑电等多模态信号的接入、标准化和特征输出。

它不是最终判断服务，而是为问诊、量表和风险决策提供辅助特征支持。

当前分工口径：

- 语音转写：朱睿
- 其他非 EEG 模态：刘倩
- EEG 模态与脑电帽硬件：金伟

## 2. 核心设计结论

- `multimodal-service` 只负责采集、转换和标准化，不负责最终风险结论。
- 多模态结果只能作为辅助依据，不能单独决定最终风险等级。
- 语音转写也归入这个服务的能力范围，便于统一时间戳、来源和特征输出。
- 这个服务要同时兼顾在线问诊和量表阶段，接口设计必须围绕“会话 + 采集片段 + 特征包”展开。

## 3. 职责边界

负责：

- 语音转写接入
- 语音情绪和声学特征抽取
- 表情特征抽取
- 姿态特征抽取
- 脑电数据接入适配
- 多模态特征标准化与汇总

不负责：

- 问诊状态机推进
- 量表计分
- 风险等级最终判定
- 干预内容推荐

## 4. 上下游

上游：

- `consultation-service`
- `assessment-service`
- 后续实时采集组件或设备接入层

下游：

- `risk-service`
- 后续特征存储数据库
- 后续模型或第三方推理组件

## 5. 当前实现状态

已实现：

- 只有健康检查占位

待实现：

- 多模态会话模型
- 语音转写接口
- 各模态采集接口
- 特征标准化与聚合输出

已知限制：

- 当前没有真实的多模态采集链路
- 尚未明确各设备的具体 SDK 和数据格式
- 还没有模态时间同步机制

## 6. 非目标

- 不在这里做最终临床风险结论
- 不把患者端实时页面交互写进本服务
- 不把多模态原始大文件无限期堆放在应用数据库里
