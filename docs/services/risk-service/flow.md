# `risk-service` 服务流程设计

## 1. 风险评估启动

1. 接收问诊结果、量表结果和多模态特征
2. 绑定规则集版本
3. 创建风险评估记录

## 2. 规则执行流程

1. 先检查硬触发条件
2. 如果命中高优先级安全条件，立即提升风险等级
3. 再执行普通聚合规则
4. 结合量表、多模态和结构化问诊结果生成最终等级

## 3. 风险结果输出

1. 输出风险等级
2. 输出风险解释
3. 输出转诊建议和生活建议
4. 生成干预入口数据
5. 必要时标记人工复核

## 4. 异常分支

- 缺少关键输入
- 规则集缺失或非法
- 高风险中断但人工复核链路不可用
- 上游多模态结果不完整

## 5. 与主流程的关系

- 正常情况下，风险结果进入 `intervention-service`
- 高风险情况下，可先标记人工复核，再决定是否继续后续标准流程
- 最终结果也会沉淀到 `followup-service`

## 6. 实现约束

- 高风险硬触发必须优先于普通聚合逻辑
- 风险解释必须可追踪到规则来源
- 多模态结果只作为辅助，不得单独决定最终等级
