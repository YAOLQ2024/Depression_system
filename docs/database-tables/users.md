# `users` 表说明

## 1. 表作用

`users` 是身份域的核心主表，用于保存系统账号、登录验证所需凭据，以及问诊准备阶段需要采集的基础人口学资料。

这张表承担两类职责：

- 身份认证基础数据：注册、登录、角色判定
- 问诊前基础资料：姓名、性别、年龄、身高体重、婚姻情况、父母情况、既往精神科就诊史

## 2. 在系统哪一步使用

1. 注册流程：写入新用户账号、密码哈希和初始角色。
2. 登录流程：按邮箱查询用户，再用 `password_hash + password_salt` 校验密码。
3. 当前用户查询流程：通过 `sessions` 表拿到 `user_id` 后，再回查本表返回公开用户信息。
4. 问诊准备更新流程：更新基础档案字段，并据此刷新 `profile_status`。
5. 问诊会话创建前：前端或 gateway 会先读取本表中的资料，作为 `participant_profile_snapshot` 传入问诊服务。

## 3. 字段说明

| 字段名 | 英文翻译 | 中文翻译 | 类型/约束 | 作用 | 为什么需要这个字段 | 主要使用步骤 |
| --- | --- | --- | --- | --- | --- | --- |
| `id` | User ID | 用户唯一标识 | `String(36)`，主键 | 标识一名用户，并作为其他表关联键。 | 如果没有稳定主键，`sessions`、问诊会话、量表会话都无法可靠关联到同一用户。 | 注册、登录、鉴权、跨服务关联 |
| `email` | Email Address | 邮箱账号 | `String(255)`，唯一索引，非空 | 作为当前系统的登录账号。 | 需要一个可唯一检索的账号标识来支持注册去重和登录查询。 | 注册、登录 |
| `password_hash` | Password Hash | 密码哈希值 | `Text`，非空 | 保存密码哈希后的结果，而不是明文密码。 | 需要避免数据库直接保存明文密码，降低泄露风险。 | 登录校验、注册写入 |
| `password_salt` | Password Salt | 密码盐值 | `Text`，非空 | 为每个用户提供独立盐值，与密码一起生成哈希。 | 需要防止相同密码产生相同哈希，降低彩虹表和撞库攻击风险。 | 注册写入、登录校验 |
| `full_name` | Full Name | 姓名 | `Text`，非空 | 保存用户显示姓名，并作为问诊准备资料的一部分。 | 问诊界面、医生称呼和基础档案都需要姓名，不能只依赖邮箱。 | 注册、问诊准备、问诊前资料加载 |
| `role` | User Role | 用户角色 | `String(32)`，非空 | 区分 `admin`、`researcher`、`participant`。 | 系统需要根据角色控制可见功能和接口权限。 | 注册、登录后权限判断 |
| `profile_status` | Profile Status | 资料完成状态 | `String(32)`，非空 | 标记用户问诊准备资料当前是草稿还是已完成。 | 前端和 gateway 需要快速知道用户是否已经完成问诊前资料，而不是每次逐字段检查。 | 问诊准备更新、问诊开始前检查 |
| `gender` | Gender | 性别 | `Text`，可空 | 保存用户性别信息。 | 基础人口学特征会影响问诊上下文表达，也是后续分析的常用背景变量。 | 问诊准备、问诊上下文快照 |
| `age` | Age | 年龄 | `Integer`，可空 | 保存年龄。 | 年龄是临床解释和问诊表达的重要上下文，后续风控和研究统计也常用。 | 问诊准备、问诊上下文快照 |
| `height_cm` | Height in Centimeters | 身高（厘米） | `Float`，可空 | 保存身高信息。 | 作为基础体征信息，便于形成较完整的患者背景资料。 | 问诊准备、问诊上下文快照 |
| `weight_kg` | Weight in Kilograms | 体重（千克） | `Float`，可空 | 保存体重信息。 | 与身高一起构成基础身体状态信息，后续如有健康分析可直接复用。 | 问诊准备、问诊上下文快照 |
| `marital_status` | Marital Status | 婚姻状况 | `Text`，可空 | 保存当前婚姻状态。 | 婚姻与亲密关系支持情况常与心理状态相关，问诊前保留有助于减少重复提问。 | 问诊准备、问诊上下文快照 |
| `parents_marital_status` | Parents' Marital Status | 父母婚姻状况 | `Text`，可空 | 保存父母婚姻关系状态。 | 家庭结构是规则式精神心理问诊的重要背景信息。 | 问诊准备、问诊上下文快照 |
| `parents_occupation` | Parents' Occupation | 父母职业情况 | `Text`，可空 | 保存父母职业信息。 | 家庭社会支持与成长环境分析常需要该背景项。 | 问诊准备、问诊上下文快照 |
| `prior_psychiatric_visit` | Prior Psychiatric Visit | 既往精神科就诊史 | `Text`，可空 | 保存是否曾接受过精神科或心理相关就诊。 | 这是后续现病史判断的重要先验信息，提前采集可以减少问诊时重复输入。 | 问诊准备、问诊上下文快照、现病史解释 |
| `created_at` | Created Time | 创建时间 | `DateTime(timezone=True)`，非空 | 记录用户创建时间。 | 需要审计账号何时建立，也便于后续统计和排障。 | 注册后审计、后台统计 |
| `updated_at` | Updated Time | 更新时间 | `DateTime(timezone=True)`，非空 | 记录用户资料最近一次更新时间。 | 需要判断资料是否刚更新过，并支持审计和缓存失效策略。 | 问诊准备更新、用户资料展示 |
