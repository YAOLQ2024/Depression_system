## 主流程设计

| 页面 | 横屏现状与竖屏基线问题 | 竖屏布局与交互决定 |
| --- | --- | --- |
| 封面 `/` | 云背景、左中标题和进入按钮；竖屏上内容小且上下留白大。 | 保留背景与品牌；标题、说明、进入按钮组成屏幕中部偏上单列，按钮加大；底部品牌信息不盖按钮。 |
| 登录 / 注册 `/login` | 横屏左视觉、右窄表单；竖屏仍是 58/42 两栏，表单小。 | 上部视觉品牌区域，下部完整宽度表单；注册增加字段后页面可滚动；密码显示、注册切换、返回均至少 48 px 触摸区。 |
| 首页 `/home` | 人物左、环绕菜单右；竖屏仍挤在中段，主入口不显著。 | 人物作为上半部视觉，下面展示明确的「开始/继续评估」主卡；历史、调节、档案和新建会话为纵向/双列次级入口。原菜单行为与状态保持。 |
| 档案 `/profile` | 亮色卡片和多组表单，已有滚动；字小、横向两列密。 | 页面滚动，摘要在前、个人信息/资料在后；表单字段单列，保存/编辑操作清楚；隐私与错误信息不被固定区遮挡。 |
| 准备 `/preparation` | 左信息卡、右三个授权步骤；竖屏左右仍挤压，末端大面积空白。 | 纵向步骤：身份/环境说明 → 设备检测 → 授权 → 医生风格/确认；底部状态与继续按钮同一阅读链。资料弹窗在小视口内滚动。 |
| 问诊 `/consultation` | 房间背景、横屏中央数字人、左侧字幕、右上摄像头和实时结果，语音球在底部；旧竖屏把人物缩小并抬高。 | 数字人放大并以可见身体底缘贴近屏幕底部，占屏宽约 40%–50%；顶部左侧放缩小的字幕矩形，右侧保留摄像头采集框；语音操作留在底部。多模态看板默认收起，点开后覆盖内容区全宽。 |
| 量表选择 `/scale-selection` | 左量表、右已选/规则；竖屏仍两列，上半段拥挤。 | 单列量表清单；选择摘要与规则在清单后；开始按钮保持可见且不会遮盖最后一张卡。选中、禁用、错误文案沿用原状态。 |
| 量表作答 `/scale-questionnaire` | 房间/人物背景、题卡绝对定位在左、字幕悬浮，摄像头右上；旧竖屏题卡与字幕重叠，数字人过小且悬空。 | 数字人放大、底缘贴近屏幕底部，占屏宽约 40%–50%；量表答题板叠在人物前方，视频播放时背景降到更透明以透出人物，播放结束恢复原灰黑透明度；字幕缩成左上矩形，摄像头框放右上；语音球留在底部。多模态看板默认收起，打开后全宽覆盖答题板。语音/点击答题均保留。 |
| 结果 `/result` | 左人物、右深色长面板；竖屏面板仍横向铺满并有巨大内部空白，后续按钮在屏幕底。 | 结果摘要首屏展示评分、风险和必要说明；证据、量表、后续建议依次纵向排列；「查看量表」「进入调节」「新会话」作为清楚的末端动作，不让风险说明折叠。 |
| 干预首页 `/intervention` | 森林与人物，底部两个入口；竖屏人物极大，控件靠屏幕底。 | 保留场景，人物缩至中部可见；视频、游戏、诗歌入口组成易触摸卡片，放在中下部可达区域；返回路径不被遮挡。 |
| 视频 `/intervention/video` | 影院背景；左播放区、右节目列表；竖屏播放区窄、控制按钮小。 | 选择前为上部 16:9 播放器、下方纵向节目列表；选择后在影院银幕中央显示 16:9 播放器和控制钮；全屏按钮保留用户手势语义。 |
| 游戏 `/intervention/game` | 包装页和心灵花园 iframe；竖屏可见但 iframe 大面积空白，帮助弹窗在中部。 | 包装页标题、返回与 iframe 纵向排列，iframe 至少占一个有效操作视口；帮助弹窗不超出屏幕，关闭和开始按钮易触摸。内部游戏另做实机点按验收。 |
| 诗歌 `/intervention/story` | 画作背景，两个横排卡片；竖屏卡片仍横排且下半屏空置。 | 标题后两张纵向大卡；进入沉浸播放时文本/播放控制保持同屏可达，背景不压低文字对比度。 |
| 历史 `/history` | 4 个统计块一排、筛选、记录列表；竖屏可滚动但标签和按钮小。 | 统计块 2 × 2 或单列；筛选清楚；记录卡主信息在左、状态/继续/详情在末端，按钮至少 48 px；加载更多可到达。 |
| 历史详情 `/history/:id` | 深色结果、依据、时间线和会话内容的长报告；竖屏可滚动但小字、密集。 | 摘要先行，评分/风险/建议后续单列；量表详情和时间线按语义顺序；问答卡可折行，保留全部风险证据。 |
| 单量表详情 `/history/:id/scale/:scaleId` | 得分/严重度/风险三列，趋势图和逐题表格。 | 得分/严重度/风险分块单列或两列；趋势图宽度自适应；逐题表在窄视口改为逐题卡，保留答案、来源、分值四类信息。 |

## 共享元素与状态

- 页头：竖屏缩短品牌占位、保证返回/通知/用户菜单可点击；弹出的菜单在视口内。
- 数字人：不得因 `object-fit: cover` 剪掉面部、嘴部和关键字幕；视频资源比例在选定模式下实测。
- 摄像头不可用：提示保留，但不能长期覆盖题目或主操作；提示可关闭或在辅助状态区显示。
- 加载、无记录、登录错误、资料未完备、设备未授权、暂停、风险、断线与会话恢复都使用同一套布局约束。
- `/labs/seamless-video-player` 是工程实验路由，不属于患者正式流程；保留横屏原样，单独标记而不纳入患者竖屏验收。
