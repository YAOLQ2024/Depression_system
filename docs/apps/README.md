# 应用文档目录说明

`docs/apps/` 用来放前端应用级设计文档，目录结构与 `apps/` 对齐。

当前约定：

- 每个应用使用独立目录：`docs/apps/<app-name>/`
- 每个应用至少先有 4 份文档：
  - `overview.md`
  - `api-and-data.md`
  - `flow.md`
  - `tasks.md`
- 新需求先改这里，再改代码
- 文档和代码冲突时，以老师确认流程和当前蓝图为准，然后同步修正文档与代码

写法要求参考了 `aic-coralreef` 的设计文档风格，统一采用：

- 全文中文
- 先写结论，再写展开说明
- 接口、数据、依赖尽量用表格说清楚
- 明确写出负责范围、不负责范围和已知限制
- 文档必须能直接指导实现，而不是只写概念

当前目录规划：

- `consultation/`
- `operations-console/`
