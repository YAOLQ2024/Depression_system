我把 V1.1 规则版“数字人交互问诊”按照老师确认的子任务流图重写了一遍。
前期仍然不上 LLM 主链，所以交互必须保持为可配置的规则树或状态机，并且每个关键节点都要覆盖“正常回答 / 沉默无反馈 / 答非所问或识别失败”三类分支。

V1.1 虚拟医生辅助问诊完整交互剧本

【模块一：初始问候与流程说明】

系统前置动作：

- 读取患者基础档案摘要。
- 读取当前会话绑定的数字人配置。
- 检查语音输入和屏幕交互状态。

数字人（温柔、专业）：

“您好，我是本次陪您完成问诊的数字医生。接下来我会先了解您这次最想解决的问题，再根据您的情况做进一步询问，之后还会邀请您完成几个量表测试。整个过程里，如果您一时不方便说话，也可以点击屏幕或使用文字输入。准备好了的话，请告诉我‘开始’。”

[患者分支 A - 正常反馈，如“好的 / 开始吧 / 可以”]

- 数字人：“好的，我们现在开始正式问诊。我会先从您这次最想咨询的问题开始了解。”

[患者分支 B - 沉默无反馈]

- 数字人：“您好，请问您能听到我的声音吗？如果准备好了，请说‘开始’，或者点击屏幕上的‘继续’按钮。”

[患者分支 C - 继续沉默或识别失败]

- 数字人：“没关系，如果您现在不方便说话，也可以通过屏幕文字输入和我交流。我先按标准流程继续，后面您随时都可以补充。”

模块输出：

- 正式问诊开始状态
- 当前会话已确认的交互方式

【模块二：主诉采集】

数字人：

“现在请您放轻松，先和我说说，您今天最想咨询或最想解决的问题是什么？最近让您最难受、最困扰的表现是什么？”

[患者分支 A - 正常回答]

- 系统执行：
  - 语音识别与文本转写
  - 提取主诉原始文本
  - 提取主诉关键词
  - 生成主诉摘要
- 数字人：“好的，我先为您记录为‘主诉摘要’。接下来我会继续了解它出现了多久、变化成什么样、以及对您生活造成了哪些影响。”

[患者分支 B - 沉默无反馈]

- 数字人：“不用着急，您可以慢慢组织语言。您也可以从一个最明显的不舒服开始说起，比如睡眠、情绪、紧张害怕、食欲或者上学上班状态。”

[患者分支 C - 答非所问 / 长时间宣泄 / 识别失败]

- 数字人：“我理解您现在可能有很多感受。为了让我先抓住最核心的问题，您能不能先用一句话告诉我，最近最困扰您的是什么？”

模块输出：

- 主诉原始文本
- 主诉关键词
- 主诉摘要

【模块三：现病史规则式问诊】

这一模块不再拆成“基础信息 / 家庭背景 / 既往史”几个产品一级阶段，而是统一放到基于主诉的规则式问诊里。

系统动作：

- 根据主诉关键词进入对应规则路径。
- 典型路径可包括：失眠路径、情绪低落路径、焦虑紧张路径、学习压力或社交功能路径、泛化兜底路径。

共性追问主题：

- 这个问题从什么时候开始
- 最近出现的频率和强度
- 是否影响睡眠、吃饭、上学、上班和社交
- 是否有明显诱因或压力事件
- 是否曾经因此去医院、学校心理中心或其他机构求助
- 如有需要，再追问家庭背景、家族史、既往精神科就诊史等补充信息

示例话术：

- 数字人：“您刚刚提到最近睡不好。我先确认一下，主要更像是入睡困难、夜里容易醒，还是醒得很早之后就很难再睡着？”
- 数字人：“这种情况大概持续多久了？是最近一两周才开始，还是已经持续了几个月？”
- 数字人：“这种状态对您的上学、上班，或者和家人同学同事相处有没有明显影响？”
- 数字人：“在这段时间里，您有没有去医院、学校心理中心，或者找其他专业人士咨询过？”

[患者分支 A - 正常回答]

- 系统执行：
  - 语音识别与文本转写
  - 当前轮结构化字段提取
  - 更新当前问诊状态
  - 保存当前轮问答记录

[患者分支 B - 沉默无反馈]

- 数字人：“没关系，我把问题换一种更简单的方式来问。”
- 若仍无反馈：
  - 提供按钮选择或文字输入兜底
  - 必要时将当前字段标记为“暂未明确”

[患者分支 C - 答非所问 / 识别失败]

- 数字人：“抱歉，我刚刚没有完全听清。我会把问题说得更直接一些，您可以简单回答‘有 / 没有’，或者用一句短话描述。”

模块输出：

- 现病史结构化结果
- 当前问诊轮次状态
- 已保存的问答记录

【模块四：高风险问题排查】

这一模块是独立安全门，不与一般追问混在一起。

数字人：

“接下来我需要例行确认几个安全相关的问题。这些问题很重要，目的是确保您现在是安全的。”

核心排查点：

- 是否出现过伤害自己的想法
- 是否出现过不想活了、想结束生命的念头
- 是否已经考虑过具体方式或计划
- 最近是否有实际冲动、尝试或明显危险行为
- 当前身边是否有人可以陪伴、帮助或及时联系

示例话术：

- 数字人：“最近这段时间，您有没有出现过想伤害自己，或者觉得不如结束生命的念头？”
- 数字人：“如果出现过类似念头，您是否已经想过要怎么做，或者最近有过差一点真的去做的情况？”
- 数字人：“如果您现在状态很差，您身边有没有家人、朋友、老师或同事可以及时联系和陪伴？”

[患者分支 A - 未触发高风险]

- 系统执行：
  - 保存高风险排查结果
  - 标记当前流程可继续
- 数字人：“感谢您的配合。语音问诊部分先到这里，接下来我们进入量表问诊阶段。”

[患者分支 B - 触发高风险]

- 系统执行：
  - 输出高风险提示
  - 标记需要人工介入或安全处置
  - 保存高风险事件记录
- 数字人：“系统识别到您当前可能存在需要立即关注的安全风险。接下来我会暂停标准流程，并协助转入人工支持或进一步安全处理。”

【平滑进入量表问诊阶段】

数字人：

“接下来我们将进入量表问诊阶段。系统会根据规则为您安排必做量表，并显示可选量表。题目会逐条展示，您只需要根据最近一段时间的真实感受作答即可。每完成一个量表，系统都会自动保存，但会在全部量表结束后再统一展示结果。”
