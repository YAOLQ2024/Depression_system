验证结果：

- 宽侧栏头像宽度从上一版约 183px 恢复至约 307px，占主体约 40%；实时区高度 520px → 360px。
- 宽侧栏三导联各约 77px，500px 侧栏各约 69px。工具栏与提示仍排在绘图区之外。
- 500px 侧栏保留完整头像和左右排列；390px 窄屏上下排列时头像高度 260px，不再使用摘要缩略图。
- 原位切换无弹窗或滚动跳动，缩放与波形节点保留，返回实时视图后持续更新；历史、迟到响应与缺失参考集检查通过。
- 500px 侧栏、1080×1920 竖屏和 390px 窄屏无横向溢出，后续模态仍可滚动到达；无 JavaScript 运行时异常。
