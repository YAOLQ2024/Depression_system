# EEG 科技感数字头模展示方案（重写版）

更新时间：2026-06-28

适用仓库：`depression-system`

适用范围：

- `apps/consultation/client`
- `docs/multiEmo`

替代说明：

1. 本文替代上一版“三联卡情绪图”方向。
2. 本文替代“单主表情但仍偏卡通脸”的方向。
3. 后续 EEG 右侧视觉实现，应以本文为唯一参考。

---

## 1. 文档目标

本文用于重新定义 EEG 右侧视觉区的目标风格与实现边界。

这次方向明确为：

1. 右侧区域始终只显示一个主头模。
2. 头模风格必须具有科技高级感。
3. 视觉核心不是“表情卡片”，而是“数字头模 + 三点位 + 情绪脑网络”。
4. 必须体现双颞叶与 `Fpz` 三个 EEG 点位，但不显示点位文字。
5. 三种情绪不只靠颜色区分，还要靠网络结构差异区分。

---

## 2. 需求确认

根据最新反馈，当前方向需要完全重写。

## 2.1 已确认的视觉目标

右侧 EEG 区域应该是：

- 单主视觉
- 正面数字头模
- 深色底
- 蓝 / 黄 / 绿三态
- 三个 EEG 关键点位可见
- 点位之间存在脑网络 / EEG 连接感
- 整体气质偏科技、克制、高级

而不是：

- 三张卡片并列
- 卡通脸
- 情绪插画
- 排行榜式概率列表

## 2.2 三个点位要求

图中必须体现以下三个点位：

1. 左颞叶点位
2. `Fpz` 点位
3. 右颞叶点位

要求：

1. 不需要写 `T7 / Fpz / T8` 文字。
2. 但必须让人一眼看出“这里有三个关键节点”。
3. 建议用高亮圆点、环形能量圈、光斑或节点脉冲来凸显。

---

## 3. 当前实现问题确认

当前实现的主要问题已经明确：

1. 视觉不够高级。
2. 头模不像数字神经头模，更像情绪插画。
3. 三联卡表达偏“列表”，不是“主状态面板”。
4. 三个 EEG 关键点位不够清晰。
5. 虽然颜色有了，但“情绪脑网络”的差异感不够。

一句话总结：

**当前实现有分类信息，但没有真正做出 EEG 科技视觉。**

---

## 4. 新的总视觉定义

## 4.1 总体构图

右侧区域推荐采用单画幅主视觉：

1. 中央是一张正面数字头模。
2. 头模轮廓由线框、点云、发光线构成。
3. 额部中央为 `Fpz` 主节点。
4. 左右太阳穴区域各有一个颞叶节点。
5. 三个节点之间通过多条脑网络连接线构成情绪 EEG 网络。
6. 底部保留情绪标签和主概率。

## 4.2 风格关键词

风格关键词必须是：

- 科技感
- 高级感
- 数字头模
- 神经连接
- 线框发光
- 医疗科技
- 深色克制

不是：

- 卡通
- 可爱
- 插画贴纸
- 夸张表情包

## 4.3 与示例图的关系

本方案允许“模仿示例图的气质”，但不能直接照搬。

必须保留的气质：

1. 正面头模
2. 三个高亮脑区点
3. 神经连接网络
4. 单色主调控制整张图
5. 深色高科技背景

必须适配当前 UI 的地方：

1. 边框更圆角
2. 发光更克制
3. 颜色更贴合当前 slate / indigo 系面板
4. 不做纯黑海报式强反差

---

## 5. 三点位表现方案

## 5.1 点位位置定义

三个关键点位在视觉上应固定：

1. `Fpz`
   - 位于前额中央靠上
   - 为主控制节点
2. 左颞叶
   - 位于头部左侧外轮廓中上区域
3. 右颞叶
   - 位于头部右侧外轮廓中上区域

## 5.2 点位表现形式

建议每个点位都由三层组成：

1. 中心实心亮点
2. 外层细环
3. 外扩柔光

推荐表达：

- 中心点：最亮
- 外环：细描边
- 柔光：低透明度扩散

这样即使不写文字，也能明显知道“这里是关键 EEG 节点”。

## 5.3 点位层级

三个点位的层级建议如下：

1. `Fpz` 亮度最高
2. 左右颞叶次高
3. 网络连线亮度低于点位

这样视觉焦点会自然落在前额中央，再扩散到双侧。

---

## 6. 情绪脑网络表现方案

这是本次方案最核心的部分。

三种情绪不能只换颜色，必须连网络结构一起变化。

## 6.1 蓝色悲伤态

情绪语义：

- 情绪低落
- 活动不均衡
- 协同不足

网络设计要求：

1. 网络较稀疏
2. 连接线偏细
3. 连接亮度偏暗
4. 左右略不对称
5. 局部有轻微下坠感

推荐具体表现：

1. `Fpz` 到双颞叶的主连接存在，但较弱
2. 内部辅助连接线数量偏少
3. 某一侧连接可略多于另一侧，制造微不平衡感
4. 弧线走向略下压，不完全舒展
5. 头模下面的能量下垂线可以更明显一点

整体感觉：

**安静、偏冷、略微收缩。**

## 6.2 黄色平静态

情绪语义：

- 情绪稳定
- 神经活动平衡
- 状态平稳

网络设计要求：

1. 三个点之间连接均匀
2. 整体对称
3. 连接稳定
4. 光线柔和

推荐具体表现：

1. `Fpz` 到左右颞叶的主弧线对称展开
2. 额部到左右半球的辅助弧线数量适中
3. 连接线粗细一致
4. 不做明显外扩爆发
5. 整体结构最规整

整体感觉：

**平衡、稳定、柔和。**

## 6.3 绿色高兴态

情绪语义：

- 情绪积极
- 协同增强
- 神经活动更活跃

网络设计要求：

1. 连接更连续
2. 连接更明亮
3. 节点周围有轻微扩散光
4. 整体更有流动感

推荐具体表现：

1. `Fpz` 与双颞叶之间的主弧线更亮、更饱满
2. 辅助连接线数量可略多
3. 节点外圈有更明显但仍克制的扩散 glow
4. 额部向下或向外的细小能量流更多
5. 头模底部的能量环略更清晰

整体感觉：

**通透、协同、向外扩张。**

---

## 7. 头模面部表情原则

虽然核心是数字头模，但面部仍应有轻微表情差异。

要求：

1. 差异要轻微
2. 不能卡通化
3. 不能像 emoji

建议：

### 蓝色悲伤态

1. 眼形稍低垂
2. 嘴部轻微下弯
3. 轮廓线更收

### 黄色平静态

1. 眼形平稳
2. 嘴部接近水平
3. 对称最强

### 绿色高兴态

1. 眼部更柔和
2. 嘴角轻微上扬
3. 面部线条略更舒展

---

## 8. 右侧面板布局建议

## 8.1 面板内部布局

右侧区建议采用如下层次：

1. 顶层：轻网格背景
2. 中层：主头模与脑网络
3. 底层：标签 chip 与百分比

推荐保留：

1. 左下角情绪标签
2. 右下角主概率

推荐移除：

1. 任何点位文字
2. `实时脑电`
3. `Device`
4. `Latest Window`
5. `500Hz`

## 8.2 背景建议

背景不要空白，也不要过花。

推荐背景元素：

1. 很轻的网格
2. 中心 radial glow
3. 深蓝灰渐变
4. 少量纵向扫描线或淡淡数字雾

不建议：

1. 星空粒子满屏飞
2. 过强镜面反射
3. 太多无意义装饰线

---

## 9. 动效建议

## 9.1 切换逻辑

右侧视觉仍按主分类切换：

- 消极 -> 蓝色悲伤网络
- 中性 -> 黄色平静网络
- 积极 -> 绿色高兴网络

## 9.2 切换动画

推荐切换顺序：

1. 主色 glow 先变化
2. 网络线亮度与密度感跟随变化
3. 面部细节平滑替换
4. 百分比数值同步刷新

推荐时长：

- `280ms ~ 420ms`

不推荐：

1. 整张图硬切
2. 翻牌动画
3. 大幅旋转

## 9.3 稳定性策略

为了避免频繁抖动，建议加轻量切换迟滞：

1. 新主类显著高于当前主类时再切
2. 或连续两次一致再切

这样能让视觉更稳，更像监测面板而不是随机跳图。

## 10. 资产制作要求

## 10.1 资源方向

资源建议改为：

- 三张同源 SVG 数字头模

推荐命名：

- `eeg-negative-neural.svg`
- `eeg-neutral-neural.svg`
- `eeg-positive-neural.svg`

## 10.2 三张资源必须统一

三张图必须保证：

1. 同一头模结构
2. 同一视角
3. 同一构图
4. 同一节点位置
5. 同一背景语言

变化只允许发生在：

1. 颜色
2. 网络稠密度
3. 亮度
4. 对称性
5. 面部细节

## 10.3 SVG 分层建议

建议把单张 SVG 拆成这些视觉层：

1. 背景柔光层
2. 网格或空间参考层
3. 头模外轮廓层
4. 点云 / 面部线框层
5. 三节点层
6. 网络弧线层
7. 能量粒子层
8. 底部能量环层

这样后续即使不换整体资源，也能单独细调网络强度。

---

## 11. 组件实现方向

## 11.1 组件角色

右侧组件建议是：

- `EegDominantHeadPanel`

职责：

1. 只显示一个主头模
2. 根据主分类切换视觉状态
3. 维护颜色、网络、表情、光效的一致性

## 11.2 数据映射

组件输入建议最少包括：

1. `primary_label`
2. `primary_score`
3. `top_3_labels`

其中：

1. `primary_label` 决定当前用哪一态资源
2. `primary_score` 决定主亮度和主能量
3. `top_3_labels` 主要保留给标题摘要使用

右侧图像区内部不再重复展示三类分布。

---

## 12. 验收标准

满足以下条件可视为本次方案达成：

1. 右侧任何时刻只显示一个主头模。
2. 图中三个 EEG 点位清晰可见，但没有文字标注。
3. 蓝 / 黄 / 绿三态不仅换色，而且网络结构明显不同。
4. 蓝色态稀疏、偏暗、略不对称、略下坠。
5. 黄色态均匀、稳定、对称、柔和。
6. 绿色态连续、明亮、带轻微扩散和流动感。
7. 整体具有科技高级感，并与当前深色 UI 协调。
8. 不再出现卡通感和三联卡列表感。

---

## 13. 一句话总结

这次 EEG 右侧视觉区应从“情绪图片组件”升级为“具有双颞叶与 `Fpz` 三点位、并能用网络结构变化表达情绪状态的科技数字头模面板”，颜色只是基础，真正的高级感来自点位、连线、对称性、亮度和流动感的整体设计。
