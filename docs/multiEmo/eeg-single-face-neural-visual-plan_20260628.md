# EEG 单主表情数字头模展示方案（替代三联卡方案）

更新时间：2026-06-28

适用仓库：`depression-system`

适用范围：

- `apps/consultation/client`
- `services/multimodal-service`
- `docs/multiEmo`

---

## 1. 文档目标

本文用于替代上一版“三张情绪图同时展示”的 EEG 右侧视觉方案，重新定义 EEG 面板的产品目标和实现边界。

本次重新思考后，目标明确为：

1. 右侧区域始终只显示一个主视觉头模，不再同时显示三张情绪卡。
2. 头模会随着 EEG 当前主分类结果，在消极 / 中性 / 积极三种状态之间切换。
3. 视觉风格从“卡片头像”改为“数字头模 / 神经流光 / 线框面部”方向。
4. 风格要参考图2的科技感，但不能照搬，要适配当前系统的深色医疗 UI、圆角玻璃面板和低刺激气质。
5. 标题行右侧继续承担分类结果摘要，右侧图像区只负责主视觉表达。

本文只定义方案，不直接改代码。

---

## 2. 本次需求确认

根据最新反馈，本次需求已经发生两个关键变化：

## 2.1 变化一：不再是三张情绪图同时显示

上一版方案的问题在于：

1. 同时显示三张情绪图卡，视觉上像“概率榜单”。
2. 这会让用户理解为“系统同时展示三种情绪状态”。
3. 但你的真实预期是“系统当前只显示一个主表情，评估切换时替换成另一个表情”。

因此，新的原则是：

**右侧区域只保留一个主头模，按当前主分类状态切换。**

## 2.2 变化二：图像风格不是卡通头像，而是数字头模

上一版方案的问题在于：

1. 图像更接近“头像卡片”或“表情插画”。
2. 科技感不足。
3. 与 EEG / 神经连接 / 脑电监测的语义不够贴合。

你的新参考图更接近：

1. 正面头模
2. 线框或点云质感
3. 神经节点连接
4. 强烈但克制的单色能量场
5. 蓝 / 黄 / 绿三种状态色

因此，新的原则是：

**右侧区域应是“单头模神经网络视觉”，而不是“表情卡片列表”。**

## 3. 对当前实现问题的确认

当前实现与目标不一致，这一点已经确认。

## 3.1 当前实现的主要偏差

当前页面中，右侧 EEG 区域的问题有：

1. 同时显示三张图卡，而不是一个主视觉。
2. 三张图卡在纵向堆叠后，视觉焦点被分散。
3. 现有图像是“脸部插画”风格，不是“数字头模”风格。
4. 当前视觉更偏“情绪标签卡”，不够像脑电可视化模块。
5. 当前方案虽然能表达三分类概率，但不符合你要的整体气质。

## 3.2 当前需求不是“概率排行图”，而是“主状态切换图”

这意味着右侧区的产品语义也要调整：

- 旧语义：同时展示三类概率强弱
- 新语义：突出当前主导情绪状态，并在状态变化时切换主视觉

所以新方案必须把重点从：

- `三分类并列展示`

转成：

- `主类驱动的单主视觉切换`

## 4. 新的产品定义

## 4.1 总体结构不变

EEG 卡片仍然保持两栏结构：

1. 左侧：三通道 EEG 波形
2. 右侧：单主表情数字头模可视化

标题行右侧仍显示分类摘要，例如：

```text
脑电情绪监测    中性 · 68%    消极24%；中性68%；积极7%
```

因此，本次不是整体推翻 EEG 卡片结构，而是重做右侧主视觉。

## 4.2 右侧区只保留一个“当前主状态头模”

新方案中，右侧区任何时刻只显示一个主头模。

切换规则：

1. 若主分类为消极，则显示蓝色消极头模。
2. 若主分类为中性，则显示黄色中性头模。
3. 若主分类为积极，则显示绿色积极头模。

不再出现：

1. 三张情绪头模同时堆叠
2. 三张卡片中间某张高亮“主导”
3. 右侧像排行榜或候选列表

## 4.3 概率信息的职责重新分配

概率信息仍保留，但不再主导右侧区布局。

职责分配建议：

1. 标题右侧摘要负责完整三分类分布。
2. 右侧主视觉内部只显示当前主类标签和主概率。
3. 其余两类概率不再在右侧图像区做三张卡分布展示。

这样可以避免信息重复，也能让右侧图像区更纯粹。

## 5. 新的视觉方向

## 5.1 视觉关键词

本次右侧图像区的风格关键词应为：

- 数字头模
- 点云面部
- 线框轮廓
- 神经节点
- 脑区连线
- 能量流动
- 医疗科技感
- 深色玻璃感 UI

不是以下风格：

- 卡通 emoji
- Q 版表情
- 手机表情贴纸
- 纯插画头像卡

## 5.2 参考图的可借鉴点

图2里真正值得借鉴的不是“具体长相”，而是这些视觉结构：

1. 正视角头模
2. 由大量点和线构成的面部轮廓
3. 额部、左右颞部有明显的节点光点
4. 节点之间有弧形能量连接
5. 单一主色贯穿全图
6. 背景很暗，主体高亮

这些结构与 EEG 当前 3 通道也很契合：

- `T7`
- `Fpz`
- `T8`

因此，新的主视觉应该围绕这三个脑电点位来构造，而不是围绕“哭脸 / 平静脸 / 笑脸插画”来构造。

## 5.3 适配当前 UI，而不是照搬参考图

不能直接照搬图2，原因有三点：

1. 图2更像全屏科技海报，不是当前系统面板组件。
2. 当前界面有明显的圆角、玻璃、深灰蓝底、低饱和发光风格。
3. 直接把图2那种纯黑高对比图塞进当前面板，会显得风格割裂。

所以适配原则应为：

1. 保留“数字头模 + 神经连线 + 单色能量”的核心语义。
2. 降低背景纯黑程度，向当前 slate / indigo 系深色靠近。
3. 发光强度比参考图更克制。
4. 头模边缘与当前卡片圆角、半透明边框、内发光协调。

---

## 6. 右侧视觉区的目标表现

## 6.1 核心构图

推荐构图：

1. 整个右侧区只有一个主容器。
2. 中间偏上的位置是一张正面数字头模。
3. 额部、左颞、右颞分别有三个高亮脑区节点。
4. 三个节点之间存在弧线或电流样连接。
5. 头模下方有轻微底座式能量环或扫描环。

视觉层级建议：

1. 最底层：深色渐变背景
2. 第二层：柔和色雾和能量场
3. 第三层：头模点云/线框
4. 第四层：脑区节点与连线
5. 第五层：主类标签与主概率

## 6.2 三种情绪状态的差异化表达

三种状态不能只换颜色，还应有轻微表情差异。

### 消极态

视觉特征建议：

1. 主色为蓝色
2. 眼部更低沉或略微下垂
3. 嘴角轻微下压
4. 连线弧线更疏、更偏冷静
5. 整体亮度略低于积极态

### 中性态

视觉特征建议：

1. 主色为黄色
2. 双眼平稳
3. 嘴部接近水平或极轻微微笑
4. 额部节点更稳定、更居中
5. 整体最平衡、最克制

### 积极态

视觉特征建议：

1. 主色为绿色
2. 眼部更柔和
3. 嘴角轻微上扬
4. 连线更饱满、更有扩散感
5. 整体亮度最高，能量感最强

注意：

这里的“表情差异”应是轻微的，不要夸张到卡通化。

## 7. 单主视觉切换逻辑

## 7.1 基本切换原则

右侧头模的切换依据只看：

- `latest_result.primary_label`

即：

1. 主标签是消极，就用消极头模
2. 主标签是中性，就用中性头模
3. 主标签是积极，就用积极头模

## 7.2 避免频繁抖动切换

因为 EEG 窗口级分类可能会在边界附近波动，如果每次都立刻换头模，页面会显得不稳定。

因此建议加入“视觉切换防抖”或“迟滞”策略。

推荐任选其一：

### 策略 A：连续两次主标签一致才切换

适合稳定性优先的场景。

### 策略 B：新标签概率超过当前标签一定阈值才切换

例如要求：

- 新标签比当前标签高 `8%~12%` 才切换

### 策略 C：先即时切色，延迟切脸

例如：

1. 颜色先改
2. 头模表情 200~300ms 后再切

P0 推荐策略 B 或 C。

## 7.3 切换动画原则

切换动画应尽量“流态化”，不要像图片闪现替换。

推荐动效：

1. 颜色光晕先过渡
2. 旧头模淡出
3. 新头模淡入
4. 节点光点亮度重新稳定

推荐时长：

- `280ms ~ 420ms`

不推荐：

1. 硬切
2. 旋转翻牌
3. 炫目缩放

---

## 8. 标题摘要与右侧主视觉的关系

## 8.1 标题继续承担“完整信息”

标题右侧仍然是 EEG 文本主信息区。

建议保留：

1. 主分类
2. 主概率
3. 三分类完整分布

例如：

```text
中性 · 68%    消极24%；中性68%；积极7%
```

## 8.2 右侧只承担“主状态视觉”

右侧区不再承担三类分布并列展示。

建议只在右侧主视觉中保留两项最少信息：

1. 当前主类标签
2. 当前主类百分比

例如：

- `中性`
- `68%`

其余两类概率不必再在右侧重复。

## 9. 资产策略

## 9.1 不建议引入实时 3D 引擎

当前前端仓库没有：

- `three`
- `@react-three/fiber`
- 现成头模 `glb/gltf`

因此本次仍不建议走实时 3D 引擎。

## 9.2 推荐使用“同一套风格的 3 张预渲染数字头模”

推荐方案：

1. 准备 3 张同源头模资产
2. 统一正视角
3. 统一构图
4. 统一点云/线框风格
5. 仅在颜色、节点光效、面部细节上做状态差异

推荐资源：

- `eeg-head-negative-neural.*`
- `eeg-head-neutral-neural.*`
- `eeg-head-positive-neural.*`

推荐格式：

- `svg`
- 或透明背景 `webp/png`

P0 更推荐：

- `svg`

原因：

1. 更适合线框和发光结构
2. 缩放更稳定
3. 容易做局部调色和样式叠加

## 9.3 三张资产必须同模同景

三张图必须满足：

1. 同一个头模结构
2. 同一视角
3. 同一镜头距离
4. 同一背景语言
5. 同一节点布局

不允许：

1. 一个是写实脸，一个是卡通脸
2. 一个近景，一个远景
3. 一个带肩部，一个只有脸

否则切换时会像“换了另一个产品模块”。

## 10. 适配当前 UI 的样式原则

## 10.1 面板气质

当前系统整体是：

- 深色
- 玻璃感
- 圆角
- 柔和描边
- 低刺激发光

因此右侧头模区也要遵守这个气质。

推荐：

1. 圆角 `14px ~ 16px`
2. 深色蓝灰背景
3. 一层很轻的 radial glow
4. 边框细、发光弱

不推荐：

1. 纯黑背景海报感
2. 过饱和荧光
3. 夸张粒子爆炸
4. 大面积纯亮黄或纯亮绿铺满

## 10.2 色彩适配建议

三类颜色建议与标题摘要保持一致：

- 消极：蓝色
- 中性：黄色
- 积极：绿色

但头模区的颜色应采用“深底 + 亮线 + 柔光”形式，不应是纯色大面积涂满。

推荐表达：

1. 头模线框用主色高亮
2. 连线和节点用主色发光
3. 背景只保留弱色雾

## 10.3 文本控量

右侧图像区的文本量必须比现在少很多。

推荐只保留：

1. 左下角情绪标签 chip
2. 右下角主概率

例如：

- 左下：`中性`
- 右下：`68%`

不要再出现：

- `实时脑电`
- `Device`
- `Latest Window`
- `window-1`
- `500Hz`

## 11. 组件级实现建议

## 11.1 组件角色重定义

上一版新增的右侧区组件如果继续沿用，应该重构为“单主视觉模式”。

推荐组件结构：

1. `EegHeaderSummary`
   - 标题右侧摘要
2. `EegDominantHeadPanel`
   - 右侧单主视觉区
3. `eegEmotionPresentation.ts`
   - 标签、颜色、资源路径、切换规则

若沿用当前命名，也至少应把原来的：

- `EegEmotionImagePanel`

重构为只显示一个主头模，而不是三联卡。

## 11.2 `EegDominantHeadPanel` 的建议职责

建议 props：

```ts
type EegDominantHeadPanelProps = {
  primaryLabel?: string | null;
  primaryScore?: number | null;
  distribution: Array<{ label: "消极" | "中性" | "积极"; score: number }>;
  deviceStatus?: string | null;
  errorMessage?: string | null;
}
```

职责：

1. 决定当前显示哪一张头模
2. 决定主色和发光强度
3. 管理切换动画
4. 处理空状态与失败状态

不负责：

1. EEG 波形
2. 标题摘要
3. 其它模态数据

## 11.3 状态层建议

建议把右侧视觉状态整理为 4 类：

1. `pending`
2. `negative`
3. `neutral`
4. `positive`
5. `failed`

其中：

- `negative / neutral / positive` 是主显示态
- `pending / failed` 是异常与等待态

## 12. 当前需要修正的实现方向

基于最新需求，下面这些实现方向已经确认不再适用：

1. 右侧三张图同时显示
2. 通过三张卡片比较概率强弱
3. 使用卡通插画脸来表达 EEG 状态
4. 把右侧区做成情绪榜单或列表

这不是样式微调，而是产品表达方式要切换。

## 13. 分阶段落地建议

## Phase 1：方案收口

目标：

1. 明确右侧只显示一个主视觉
2. 明确数字头模风格
3. 明确三张状态资产是同源头模

本文即用于完成这一步。

## Phase 2：重做视觉资产

目标：

1. 废弃当前三联卡图像资源
2. 准备 3 张新的数字头模状态图
3. 保证蓝 / 黄 / 绿三态统一风格

## Phase 3：重构右侧组件

目标：

1. 将三联卡组件改为单主视觉组件
2. 接入切换动画
3. 保留标题摘要

## Phase 4：稳定性优化

目标：

1. 增加状态切换防抖
2. 优化等待态和失败态
3. 调整 glow 强度，防止与现有 UI 冲突

---

## 14. 验收标准

满足以下条件可视为本次方案达成：

1. 右侧区域任何时刻只显示一个主头模。
2. 主头模会随主分类在消极 / 中性 / 积极之间切换。
3. 头模风格是数字线框 / 点云 / 神经连线，而不是卡通头像。
4. 蓝 / 黄 / 绿三态清晰可辨，但整体仍与当前深色 UI 协调。
5. 标题右侧仍保留完整分类摘要。
6. 右侧区不再出现 `Device / Latest Window / 实时脑电 / 500Hz / window-*`。
7. 切换时有平滑过渡，不会生硬闪烁。

---

## 15. 一句话总结

新的 EEG 右侧视觉方案，不再是“三张情绪卡并列展示概率”，而是“一个数字神经头模作为当前主状态视觉，随着 EEG 主分类结果在蓝 / 黄 / 绿三种情绪态之间切换”，并整体适配当前系统的深色医疗科技界面。
